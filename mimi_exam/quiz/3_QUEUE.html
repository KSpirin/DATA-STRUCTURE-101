03. Queue ADT

Q1
In an array-based Circular Queue of size N, which of the following expressions correctly wraps the tail pointer index iback during enqueue?
Circular indices wrap around using modulo capacity arithmetic: (index + 1) % N.
Q2
Which of the following conditions represents a full Circular Queue when the front index wraps around and is positioned immediately after rear?
A circular queue is full under two configurations: 1) FRONT == 0 && REAR == SIZE - 1 and 2) FRONT == REAR + 1.
Q3
Performing a Breadth-First Search (BFS) directory tree starting at root node A (with children B and E, where B has children C and D, and E has child F) yields which sequence?
BFS processes level-by-level: Level 0 (A), Level 1 (B, E), Level 2 (C, D, F). Thus: A -> B, E -> C, D, F.
Q4
In a Queue ADT, elements are inserted at the ______ and removed from the ______.
Queues follow First-In, First-Out (FIFO). New elements are enqueued at the back/rear, and removed from the front.
Q5
What is the time complexity of enqueuing an element into a Circular Queue?
Circular Queue insertions run in constant $\mathcal{O}(1)$ time.
Q6
What is a Double-Ended Queue (Deque)?
A Deque (Double-Ended Queue) allows elements to be enqueued or dequeued from either the front or the back.
Q7
What is the minimum number of queues required to implement a Stack ADT?
To simulate LIFO using queues, you need at least two queues.
Q8
What is the time complexity of checking whether a Queue is empty?
Checking if a queue is empty is a constant-time check: either testing size == 0 or front == -1.
Q9
How does a Priority Queue differ from a standard FIFO Queue?
In a Priority Queue, elements are enqueued normally but dequeued based on priority.
Q10
Which OS mechanism uses Queues to manage processes waiting for CPU execution time?
Operating systems use scheduling queues (Ready Queue) to manage active process threads waiting for CPU execution time.
Q11
Which data structure operates on a Restricted-Access FIFO policy?
Queues strictly restrict insertions to the back (enqueue) and deletions to the front (dequeue), enforcing First-In, First-Out (FIFO) policies.
Q12
In a Circular Queue of size N, how is the current size calculated from front and rear indices?
If the queue has wrapped, `rear < front`. The general formula to compute elements in flight is (rear - front + N) % N.
Q13
How can you implement a Stack using two Queues?
By pushing elements to an empty helper queue, then dumping all existing elements on top of it, we reverse queue order to simulate LIFO.
Q14
What is the front-pointing index in a Circular Queue after enqueuing 3 elements and dequeueing 2 elements (starting from empty at index 0)?
Enqueuing 3 elements fills indices 0, 1, 2. Dequeueing 2 elements removes index 0 and index 1. The front pointer now rests at index 2.
Q15
Which Queue variation is commonly used in network packet buffers to prioritize bandwidth for critical traffic?
Priority Queues sort incoming packets based on their header priorities, serving high-priority packets first.
Q16
What is the value of rear and front after enqueuing 3 elements and dequeueing 2 elements in a Circular Queue? (Assuming 0-indexed empty queue starts at index 0)
1) Enqueue 3 elements fills index 0, 1, and 2. rear is at 2. 2) Dequeuing 2 elements removes index 0 and 1. The front pointer moves to index 2. Both front and rear now rest at index 2.
Q17
Read the following queue simulation. What is printed?
#include <iostream>
#include <queue>
int main() {
    std::queue<int> q;
    q.push(1); q.push(2); q.push(3);
    q.pop();
    q.push(4);
    while(!q.empty()) {
        std::cout << q.front() << " ";
        q.pop();
    }
    return 0;
}
The queue starts as [1, 2, 3]. Popping removes the front element (1), leaving [2, 3]. Pushing 4 yields [2, 3, 4]. Printing front and popping sequentially outputs '2 3 4 '.
