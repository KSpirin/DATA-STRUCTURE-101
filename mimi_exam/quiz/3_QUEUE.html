03. Queue ADT

Q1
In an array-based Circular Queue of size N, which of the following expressions correctly wraps the tail pointer index iback during enqueue?
Circular indices wrap around using modulo capacity arithmetic: (index + 1) % N.
Q2
Which of the following conditions represents a full Circular Queue when the front index wraps around and is positioned immediately after rear?
A circular queue is full under two configurations: 1) FRONT == 0 && REAR == SIZE - 1 and 2) FRONT == REAR + 1.
Q3
Performing a Breadth-First Search (BFS) directory tree starting at root node A (with children B and E, where B has children C and D, and E has child F) yields which sequence?
BFS processes level-by-level: Level 0 (A), Level 1 (B, E), Level 2 (C, D, F). Thus: A -> B, E -> C, D, F.
Q4
In a Queue ADT, elements are inserted at the ______ and removed from the ______.
Queues follow First-In, First-Out (FIFO). New elements are enqueued at the back/rear, and removed from the front.
Q5
What is the time complexity of enqueuing an element into a Circular Queue?
Circular Queue insertions run in constant $\mathcal{O}(1)$ time.
Q6
What is a Double-Ended Queue (Deque)?
A Deque (Double-Ended Queue) allows elements to be enqueued or dequeued from either the front or the back.
Q7
What is the minimum number of queues required to implement a Stack ADT?
To simulate LIFO using queues, you need at least two queues.
Q8
What is the time complexity of checking whether a Queue is empty?
Checking if a queue is empty is a constant-time check: either testing size == 0 or front == -1.
Q9
How does a Priority Queue differ from a standard FIFO Queue?
In a Priority Queue, elements are enqueued normally but dequeued based on priority.
Q10
Which OS mechanism uses Queues to manage processes waiting for CPU execution time?
Operating systems use scheduling queues (Ready Queue) to manage active process threads waiting for CPU execution time.
Q11
Which data structure operates on a Restricted-Access FIFO policy?
Queues strictly restrict insertions to the back (enqueue) and deletions to the front (dequeue), enforcing First-In, First-Out (FIFO) policies.
Q12
In a Circular Queue of size N, how is the current size calculated from front and rear indices?
If the queue has wrapped, `rear < front`. The general formula to compute elements in flight is (rear - front + N) % N.
Q13
How can you implement a Stack using two Queues?
By pushing elements to an empty helper queue, then dumping all existing elements on top of it, we reverse queue order to simulate LIFO.
Q14
What is the front-pointing index in a Circular Queue after enqueuing 3 elements and dequeueing 2 elements (starting from empty at index 0)?
Enqueuing 3 elements fills indices 0, 1, 2. Dequeueing 2 elements removes index 0 and index 1. The front pointer now rests at index 2.
Q15
Which Queue variation is commonly used in network packet buffers to prioritize bandwidth for critical traffic?
Priority Queues sort incoming packets based on their header priorities, serving high-priority packets first.
Q16
What is the value of rear and front after enqueuing 3 elements and dequeueing 2 elements in a Circular Queue? (Assuming 0-indexed empty queue starts at index 0)
1) Enqueue 3 elements fills index 0, 1, and 2. rear is at 2. 2) Dequeuing 2 elements removes index 0 and 1. The front pointer moves to index 2. Both front and rear now rest at index 2.
Q17
Read the following queue simulation. What is printed?
#include <iostream>
#include <queue>
int main() {
    std::queue<int> q;
    q.push(1); q.push(2); q.push(3);
    q.pop();
    q.push(4);
    while(!q.empty()) {
        std::cout << q.front() << " ";
        q.pop();
    }
    return 0;
}
The queue starts as [1, 2, 3]. Popping removes the front element (1), leaving [2, 3]. Pushing 4 yields [2, 3, 4]. Printing front and popping sequentially outputs '2 3 4 '.
Q18
A Circular Queue has capacity N=5 (using the 'leave one slot empty' strategy) and starts with front=0, rear=0. After enqueue(A), enqueue(B), enqueue(C), enqueue(D), what are the values of front and rear?
Each enqueue writes at rear then advances: rear = (rear+1)%5. Starting rear=0: after A, rear=1; after B, rear=2; after C, rear=3; after D, rear=4. front never moves during enqueue, so front stays 0. Final: front=0, rear=4.
Q19
Continuing from the same circular queue (N=5, front=0, rear=4 after enqueuing A,B,C,D), perform dequeue(); dequeue();. What are the new values of front and rear?
Each dequeue reads at front then advances: front = (front+1)%5. Starting front=0: after first dequeue (removes A), front=1; after second dequeue (removes B), front=2. rear is untouched by dequeue, staying at 4. Final: front=2, rear=4.
Q20
In the 'leave one slot empty' circular queue strategy with capacity N=5, the queue is currently full according to (rear+1)%N == front. If front=3 and the queue is full, what is rear?
Full condition: (rear+1) % 5 == front == 3, so rear+1 ≡ 3 (mod 5), meaning rear = 2 (since (2+1)%5 = 3).
Q21
Trace a Round-Robin CPU scheduler with a circular queue holding processes [P1, P2, P3] (P1 at front) and a fixed time quantum. After P1 runs and is not finished, it is re-enqueued. What is the queue order immediately after P1's turn?
Round-Robin dequeues the front process (P1), runs it for one quantum, and if it isn't finished, enqueues it back at the rear. The queue becomes [P2, P3, P1], with P2 now at the front for the next turn.
Q22
Simulate BFS on a tree where node A has children B and C; B has children D and E. Starting the queue with just [A], what is the queue's content immediately after processing (popping) node B?
Start: [A]. Pop A, push its children B, C -> [B, C]. Pop B, push its children D, E -> [C, D, E]. That is the state immediately after processing B.
Q23
What is the output of this std::queue trace?
#include <iostream>
#include <queue>
int main() {
    std::queue<int> q;
    q.push(1); q.push(2); q.push(3);
    q.pop();
    q.push(4);
    std::cout << q.front() << " " << q.back();
}
Push 1,2,3 -> queue: [1,2,3] (front=1). pop() removes 1 -> [2,3]. push(4) -> [2,3,4]. front() = 2, back() = 4. Output: '2 4'.
Q24
Using the 'Simple Queue' (non-circular, slide model) with front=1, rear=0, size=4 initially, after enqueue(A); enqueue(B); enqueue(C); enqueue(D); the queue reports full()==true. If we now call dequeue() four times to empty it, can we enqueue(E) afterward? Why?
In the simple (non-circular) array queue, rear only increases and is never reset by dequeue. After 4 enqueues, rear=4=size, so full() stays true forever even after the queue becomes logically empty — this is the Rightward Drift problem that circular queues solve.
Q25
In the 'Design Circular Queue' problem (LeetCode 622) using head/tail pointers and modulo indexing, what expression computes the next tail index for a queue of capacity K?
Circular indexing always wraps using modulo arithmetic against the capacity: the next tail position is (tail + 1) % K, ensuring the index cycles back to 0 after reaching K-1.
Q26
Trace the Sliding Window Maximum algorithm (monotonic deque of indices) on array [1, 3, -1, -3, 5] with window size K=3. After processing the first 3 elements (indices 0,1,2), what index is at the front of the deque?
Process idx0 (val=1): deque=[0]. idx1 (val=3): 3 >= arr[0]=1, pop idx0, deque=[1]. idx2 (val=-1): -1 < arr[1]=3, just push, deque=[1,2]. Front of the deque is index 1 (value 3), the maximum of the first window.
Q27
A single queue is used to emulate a Stack's push operation by rotating existing elements behind the newly pushed one. If the queue currently holds [X, Y, Z] (X at front) and we push W using this rotation technique, what is the queue's final order?
Enqueue W first: [X,Y,Z,W]. Then rotate 3 times (once per pre-existing element), each time dequeuing the front and immediately re-enqueuing it: [Y,Z,W,X] -> [Z,W,X,Y] -> [W,X,Y,Z]. W ends up at the front, matching stack-top (most-recently-pushed) semantics.
Q28
What is the time complexity of the 'push' operation in the single-queue Stack-emulation technique (rotate N-1 elements behind the new one), given N existing elements?
Every push must rotate all previously existing elements (N of them) to move the new element to the front of the queue, making each push operation O(N) in the worst case.
Q29
In the Dota2 Senate simulation, two queues hold voting indices for Radiant and Dire. If Radiant's front index is 2 and Dire's front index is 5 (senate length N=7), what happens on this turn?
The senator with the smaller front index acts first (bans the opponent at the other queue's front) and is re-enqueued at the back with N added to its index, to correctly represent its turn order in the next round. Since 2 < 5, Radiant bans Dire's senator and re-enqueues itself as 2+7=9.
Q30
In the 'Number of Recent Calls' problem (LeetCode 933), a queue stores request timestamps and must count requests within the last 3000ms window. If the queue holds [1000, 2500, 3200, 4100] and a new request arrives at t=4500, which timestamps are popped from the front before returning the count?
The valid window is [t-3000, t] = [1500, 4500]. We pop from the front while the front timestamp is less than t-3000=1500. Only 1000 qualifies (1000 < 1500), so it's popped. 2500 is not popped since 2500 ≥ 1500. After popping, the queue is [2500, 3200, 4100, 4500], giving a count of 4.
