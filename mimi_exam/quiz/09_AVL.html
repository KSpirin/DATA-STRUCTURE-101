09. AVL Tree

Q1
What is the defining condition for a Binary Search Tree to be considered an AVL tree?
An AVL tree balance condition: height difference between left and right subtrees must be -1, 0, or 1.
Q2
Which rotation is used to rebalance an AVL tree after an insertion causes an imbalance in the left subtree of the left child (Left-Left imbalance)?
A Left-Left (LL) imbalance is resolved by performing a single Right Rotation.
Q3
What rebalancing sequence is required for a Left-Right (LR) imbalance?
An LR imbalance requires a double rotation: first Left Rotation on the left child, then Right Rotation on parent.
Q4
What is the guaranteed worst-case search, insertion, and deletion time complexity in an AVL tree of size N?
By maintaining height balance, an AVL tree's depth is bounded at $\mathcal{O}(\log N)$.
Q5
How is the Balance Factor (BF) of a node calculated?
Standard academic definition: Balance Factor = Height(Left Subtree) - Height(Right Subtree).
Q6
How many rotations are required to restore balance in an AVL tree after inserting a single new node?
For insertions in an AVL tree, performing at most one single or double rotation restores balance.
Q7
What is the balance factor of any leaf node in a balanced AVL tree?
Leaf nodes have no children, so Balance Factor = 0 - 0 = 0.
Q8
What is the minimum number of nodes in an AVL tree of height H = 3?
N(H) = N(H-1) + N(H-2) + 1. For H=3: N(3) = 2 + 1 + 1 = 4 nodes.
Q9
If the left subtree of node A has a height of 5 and the right subtree has a height of 3, what is the balance factor of node A?
Balance Factor = Height(Left) - Height(Right) = 5 - 3 = 2.
Q10
How does an AVL tree compare to a Red-Black tree?
AVL trees maintain a stricter balance than Red-Black trees, giving faster lookups but slower updates.
Q11
Which of the following is a valid AVL tree balance factor for a node?
An AVL tree node balance factor must be in the range $[-1, 1]$. `1` is valid. `-2` and `2` are unbalanced.
Q12
What rotation is performed for a Right-Left (RL) imbalance in an AVL tree?
An RL imbalance requires a double rotation: first perform a Right Rotation on the right child, then a Left Rotation on the parent node.
Q13
What is the worst-case space complexity of storing an AVL tree of size N?
Each node in an AVL tree stores data, height, left pointer, and right pointer, taking linear $\mathcal{O}(N)$ space.
Q14
If we delete a node from an AVL tree, what is the maximum number of rotations that may be required to restore balance?
Unlike insertion (which requires at most 1 rotation), deleting a node can propagate imbalances up the tree, requiring up to $O(\log N)$ rotations.
Q15
Which self-balancing binary search tree maintains a height limit of at most $1.44 \log_2 N$?
Due to its strict height-balanced condition ($BF \in [-1, 1]$), the maximum height of an AVL tree of size $N$ is mathematically bounded at $1.44 \log_2 N$.
Q16
An AVL node A has a left subtree height of 3 and a right subtree height of 1. What is the Balance Factor (BF) of node A?
Using the academic definition: Balance Factor = Height(Left Subtree) - Height(Right Subtree). Therefore, BF = 3 - 1 = 2.
Q17
An AVL tree experiences a Left-Left (LL) imbalance: root 30 has left child 20, which has left child 10. What is the structure of the tree after a single Right Rotation at 30?
A single Right Rotation at 30 elevates 20 to the root, pivots 30 to become the right child of 20, and keeps 10 as the left child of 20.
