06. Heap / Priority Queue

Q1
Given a 0-indexed array representing a complete binary tree, if a parent node is located at index i, what is the index of its left child?
In a 0-indexed complete binary tree array: Left child is at `2i + 1`, Right child is at `2i + 2`, and Parent is at `(i-1)/2`.
Q2
What is the time complexity of the bottom-up heap construction algorithm (buildHeap / heapify)?
Bottom-up heap construction runs in linear $\mathcal{O}(N)$ time.
Q3
In a Max-Heap, where is the largest key always stored?
By Max-Heap ordering properties, every parent's value must be greater than its children's. Thus, the absolute maximum must reside at the root.
Q4
Which operation is used to restore heap order properties after removing the root element?
After pop, we place the last leaf at the root and restore heap ordering by sinking it down (heapifyDown).
Q5
What is the time complexity of sorting an array of size N using Heap Sort?
Heap Sort extracts the max element $N$ times. Each extraction takes $O(\log N)$ heapify time, yielding a total time complexity of $\mathcal{O}(N \log N)$.
Q6
What is the minimum number of elements in a binary heap of height H?
A complete binary tree of height H has Level H-1 completely filled (containing $2^{H-1}-1$ nodes) and at least 1 node at Level H. So: $(2^{H-1}-1) + 1 = 2^{H-1}$ nodes.
Q7
Under what condition can a Binary Search Tree (BST) be a valid Min-Heap?
In a BST, Left < Root < Right. In a Min-Heap, Root < Left and Root < Right. For both to hold, the tree can have at most one right child. Any left child violates Min-Heap because Left < Root.
Q8
For a 1-indexed array representation of a heap, what is the parent index of node i?
In a 1-indexed heap array representation: Parent is at `i/2` (using integer division).
Q9
What is the time complexity of the decreaseKey operation in a binary heap of size N if the target node's index is already known?
Decreasing a key in a Min-Heap means it may bubble up. The maximum height is $O(\log N)$, so the bubble-up process takes $\mathcal{O}(\log N)$ time.
Q10
In a Min-Heap, what is the relation between parent node P and child node C?
The Min-Heap property requires that every parent node's value must be less than or equal to its children's values: P <= C.
Q11
What is the height of a binary heap containing N elements?
Because a heap is a complete binary tree, its level depth is tightly bounded at $\lceil \log_2(N+1) \rceil$, yielding $O(\log N)$ height.
Q12
In a Min-Heap, where is the second smallest key stored?
The smallest key is at the root. The second smallest key must be one of the children of the root (index 1 or index 2).
Q13
What is the time complexity of extracting the maximum element from a Max-Heap of size N?
Extracting the root takes constant time, but rebuilding the heap via heapifyDown takes $O(\log N)$ time.
Q14
Which of the following represents the array state of a Max-Heap after inserting 35 into: [30, 20, 10]?
1) Insert 35 as last leaf: `[30, 20, 10, 35]`. 2) Parent of 35 is 20 (index 1). Since $35 > 20$, swap: `[30, 35, 10, 20]`. 3) Parent of 35 is 30 (index 0). Since $35 > 30$, swap: `[35, 30, 10, 20]`.
Q15
What type of priority queue does Dijkstra's shortest path algorithm use to greedily extract the closest unvisited vertex?
Dijkstra's algorithm extracts the vertex with the minimum tentative distance, requiring a Min-Priority Queue (Min-Heap).
Q16
For a max-heap represented by array [90, 80, 70, 50, 60], which node is the parent of 60 (index 4)?
In a 0-indexed complete binary tree array, the parent of index i is (i - 1) / 2. For index 4, parent index is (4-1)/2 = 1. Index 1 contains 80.
Q17
Given array representation [10, 80, 90], what does the array look like after executing heapifyDown(0) to restore Min-Heap properties?
The root element is 10. Its children are 80 (left) and 90 (right). Since 10 is already smaller than both children, the min-heap property holds and no swaps occur. The array remains [10, 80, 90].
