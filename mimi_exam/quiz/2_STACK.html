02. Stack ADT

Q1
What is the postfix (Reverse Polish) representation of the infix expression: A + B * (C - D) / E?
Following operator precedence: 1) `(C - D)` -> `C D -`. 2) Multiply by `B` -> `B C D - *`. 3) Divide by `E` -> `B C D - * E /`. 4) Add `A` -> `A B C D - * E / +`.
Q2
For a stack implemented using a fixed-size array of capacity N with the top-index tracking variable top initialized to 0 (where data is pushed into index top and then top is incremented), what represents the stack full condition?
If top starts at 0 and increments after pushing, it equals the current size. The stack is full when size reaches capacity: top == N.
Q3
Which of the following describes the operational behavior of a Stack?
Stacks follow Last-In, First-Out (LIFO) behavior. Insertions and removals are only performed at one end (the top).
Q4
Using a stack, what is the output of evaluating the following postfix expression: 10 4 2 / + 5 *?
1) Push 10, 4, 2. 2) `/` pop 2, 4 -> 4/2 = 2. Push 2. 3) `+` pop 2, 10 -> 10+2 = 12. Push 12. 4) Push 5. 5) `*` pop 5, 12 -> 12 * 5 = 60.
Q5
When parsing XHTML tags with a stack, which condition indicates a syntax nesting error?
Nesting requires that any closing tag must match the most recently pushed opening tag. If the popped tag doesn't match, or the stack is empty during a pop, the tags are mismatched.
Q6
Which data structure is typically used to implement the 'Back' and 'Forward' navigation history in web browsers?
Web browsers use two stacks: a 'Back' stack and a 'Forward' stack. Clicking a link pushes the current page to the 'Back' stack and clears the 'Forward' stack.
Q7
What is the time complexity to retrieve the minimum element from a standard, non-auxiliary Stack ADT of size N?
A standard stack only exposes the top element. Finding the minimum requires popping all elements to inspect them, taking linear $\mathcal{O}(N)$ time.
Q8
Which of the following defines a 'Monotonic Decreasing Stack'?
A Monotonic Decreasing Stack maintains its elements in strictly decreasing order from bottom to top (each pushed element is smaller than the one below it).
Q9
Convert the Prefix expression * + A B - C D to Postfix.
Prefix `* + A B - C D` evaluates as: 1) `+ A B` -> `(A+B)`. 2) `- C D` -> `(C-D)`. 3) `*` applied to results -> `(A+B) * (C-D)`, which in postfix is `A B + C D - *`.
Q10
What occurs when an application attempts to push an element onto an array-based stack that has reached its capacity limit?
Pushing onto a stack that has exceeded its storage capacity triggers a Stack Overflow condition.
Q11
In an infix-to-postfix conversion algorithm using a stack, what is done when an operator is parsed?
Operators are stored on the stack. To maintain precedence, before pushing a new operator, we must pop and print any stack operators that have greater or equal precedence.
Q12
What is the primary drawback of using a singly linked list to implement a Stack ADT?
A linked list stack grows dynamically (no overflow), but every node incurs pointer overhead (8 bytes on 64-bit systems) in addition to the data storage.
Q13
Which stack-based traversal algorithm matches Depth-First Search?
Preorder and DFS traversals utilize a LIFO Stack structure to track nodes along a single path before backtracking.
Q14
What is the prefix representation of the infix expression: A * B + C?
1) `A * B` -> `* A B`. 2) Add `C` -> `+ * A B C`.
Q15
If a stack contains elements [X, Y, Z] (Z is top) and we perform: push(W), pop(), pop(), what is the top element?
1) Initial: `[X, Y, Z]`. 2) Push W -> `[X, Y, Z, W]`. 3) Pop -> pops W, stack becomes `[X, Y, Z]`. 4) Pop -> pops Z, stack becomes `[X, Y]`. Top is Y.
Q16
Determine the output of the following stack operations:
#include <iostream>
#include <stack>
int main() {
    std::stack<int> s;
    s.push(10);
    s.push(20);
    std::cout << s.top() << " ";
    s.pop();
    s.push(30);
    s.pop();
    std::cout << s.top();
    return 0;
}
1) Push 10, push 20. 2) s.top() prints 20. 3) s.pop() removes 20 (stack is [10]). 4) s.push(30) makes stack [10, 30]. 5) s.pop() removes 30 (stack is [10]). 6) s.top() prints 10. Output: '20 10'.
Q17
A parsing program executes this function. What does it return for the string "(()))"?
#include <stack>
#include <string>
bool check(std::string s) {
    std::stack<char> st;
    for(char c : s) {
        if(c == '(') st.push(c);
        else if(c == ')') {
            if(st.empty()) return false;
            st.pop();
        }
    }
    return st.empty();
}
The string has two open parentheses, which are pushed. The first two close parentheses pop them, leaving the stack empty. The third close parenthesis encounters an empty stack (st.empty() is true) and returns false.
