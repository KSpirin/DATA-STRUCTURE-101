10. Graphs

Q1
Which graph representation has a space complexity of $\mathcal{O}(V^2)$ where $V$ is the number of vertices?
An Adjacency Matrix always consumes $\mathcal{O}(V^2)$ space.
Q2
Which property must be tracked during Kahn's Topological Sort algorithm to select the next vertex?
Kahn's algorithm selects vertices with no incoming edges (In-degree = 0).
Q3
What is the worst-case time complexity of Warshall's Algorithm to compute Transitive Closure?
Warshall's algorithm uses three nested loops over the vertices, giving a time complexity of $\mathcal{O}(V^3)$.
Q4
In a DFS traversal forest on a directed graph, what edge type points to an ancestor node and signals cycle presence?
A Back Edge points from a vertex to an ancestor in the DFS tree, indicating a cycle.
Q5
Which algorithm finds the single-source shortest path on a weighted directed graph in $\mathcal{O}(E \log V)$ time?
Dijkstra's shortest path algorithm using a min-priority queue runs in $O(E \log V)$ time.
Q6
What is the maximum number of edges in a simple undirected graph with V vertices?
For undirected graphs, each edge is shared: $V(V-1) / 2$.
Q7
What state tracking mechanism does BFS use to prevent infinite loops in cyclic graphs?
BFS maintains a visited array/set to prevent reprocessing cyclic vertices.
Q8
Topological sorting can be performed only on which type of graphs?
A topological sort requires directed edges to define order and must be acyclic (no cycles).
Q9
What is a Bipartite Graph?
A Bipartite Graph is 2-colorable: vertices partition into two sets with no edges linking same-set vertices.
Q10
What property of a graph do Kruskal's and Prim's algorithms find?
Kruskal's and Prim's algorithms find the Minimum Spanning Tree (MST) of a weighted graph.
Q11
What is the space complexity of representing a sparse graph with V vertices and E edges using an Adjacency List?
Adjacency lists store an array of size $V$ pointing to lists containing $E$ edge connections, taking $\mathcal{O}(V + E)$ space.
Q12
Which vertex traversal uses a Queue to explore neighbors level-by-level?
BFS explores graph vertices level-by-level, utilizing a FIFO Queue to enqueue adjacent nodes.
Q13
What is a Spanning Tree of a graph?
A spanning tree is a subset of graph edges that connects all vertices together without forming any cycles.
Q14
What algorithm checks if a directed graph contains a cycle using DFS coloring (white, gray, black)?
DFS cycle detection uses node coloring: visiting a gray node (ancestor) represents a back edge, signaling a cycle.
Q15
What is the time complexity of Prim's MST algorithm using an adjacency list and binary min-heap?
Using a binary min-priority queue and adjacency lists, Prim's algorithm runs in $O(E \log V)$ time.
Q16
Evaluate this adjacency list wiring logic. Is there a path from node 0 to node 2?
std::vector<std::vector<int>> adj(3);
adj[0].push_back(1);
adj[1].push_back(2);
Node 0 is connected to node 1. Node 1 is connected to node 2. This forms a directed path: 0 -> 1 -> 2, connecting 0 to 2.
Q17
A directed acyclic graph contains edges: 1 -> 2 and 2 -> 3. Which of the following is a valid topological sort sequence?
By definition, topological sort requires that for every directed edge u -> v, node u must appear before node v. Thus, 1 must precede 2, and 2 must precede 3, giving 1, 2, 3.
