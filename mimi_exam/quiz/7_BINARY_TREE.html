07. Binary Tree

Q1
What is the maximum number of leaves in a binary tree of height H?
A perfect binary tree of height H has $2^{H-1}$ leaves at the bottom level.
Q2
Which traversal order processes the root node after recursively traversing both its left and right subtrees?
Postorder visits subtrees first: Left subtree -> Right subtree -> Root node.
Q3
An Expression Tree's postorder traversal yields which algebraic representation?
Postorder traversal processes operator nodes after their children operands, naturally outputting Postfix (Reverse Polish) algebraic notation.
Q4
What is the degree of a leaf node in a rooted tree structure?
A leaf node is defined as a node with no successors (no children). Therefore, its child degree is exactly 0.
Q5
Which helper data structure is typically used to implement an iterative DFS traversal of a binary tree?
Iterative DFS traversals simulate recursion using an explicit LIFO Stack.
Q6
If a binary tree contains N nodes, how many null pointers (empty child links) are present in the tree?
Each node has 2 child pointers, giving $2N$ total pointers. Since $N-1$ pointers are used to link parent-child connections, there are $2N - (N-1) = N+1$ null pointers.
Q7
What is the maximum height of a binary tree containing L leaves?
To maximize height, we should have a skewed chain of nodes where each level has 1 child, except the lowest levels. For $L$ leaves, the maximum height is $L$.
Q8
What is the relation between the number of leaf nodes ($n_0$) and the number of nodes with degree 2 ($n_2$) in any binary tree?
By algebraic tree properties: the number of leaf nodes (degree 0) is always exactly 1 more than the number of internal nodes with two children (degree 2): $n_0 = n_2 + 1$.
Q9
Given a Preorder traversal sequence: A B D E C F and an Inorder sequence: D B E A F C, what is the Postorder traversal?
Rebuilding recursively yields left child B (with children D, E) and right child C (with left child F). Postorder is Left -> Right -> Root: `D E B F C A`.
Q10
What is the height of a perfect binary tree containing 15 nodes?
A perfect binary tree has $2^H - 1$ nodes. For 15 nodes, $2^H - 1 = 15 \implies 2^H = 16 \implies H = 4$ levels.
Q11
A full binary tree has 9 internal nodes. How many leaf nodes does it contain?
In any full binary tree (every node has 0 or 2 children), the number of leaf nodes $L$ is related to internal nodes $I$ by: $L = I + 1$. Thus, $9 + 1 = 10$ leaf nodes.
Q12
What is the maximum height of a binary tree with 7 nodes?
The maximum height occurs when the tree is completely skewed (linear chain), giving a height equal to the number of nodes: 7.
Q13
Which binary tree traversal visits nodes in BFS level-order?
Level-order traversal visits nodes level-by-level, starting from the root, going left-to-right on each level.
Q14
What is the relationship between the number of edges E and vertices V in a binary tree?
Every tree with $V$ vertices has exactly $V-1$ edges, as every node except the root has exactly one parent edge.
Q15
What is the height of a perfect binary tree with 31 nodes?
A perfect tree has $2^H - 1$ nodes. For 31 nodes: $2^H - 1 = 31 \implies 2^H = 32 \implies H = 5$.
Q16
What is printed by executing traverse(root) on a tree where Root (1) has Left child (2) and Right child (3)?
void traverse(Node* root) {
    if(!root) return;
    std::cout << root->val << " ";
    traverse(root->left);
    traverse(root->right);
}
This implements Preorder Traversal (Root, Left, Right). For root 1, it prints 1, then traverses left child 2 (printing 2), then traverses right child 3 (printing 3). Output: '1 2 3 '.
Q17
What does the function count(root) return if root points to a leaf node in a binary tree?
int count(Node* root) {
    if(!root) return 0;
    return 1 + count(root->left) + count(root->right);
}
For a leaf node, root->left and root->right are both nullptr. The recursive calls return 0. The expression evaluates to: 1 + 0 + 0 = 1.
